# V60: método Hoffmann de dos pulsos (base general para lavados y frutales delicados)

- Molienda media-fina.
- 0:00: bloom con ~2 veces el peso del café.
- 0:45: primer vertido hasta el 60% del agua total.
- 1:15: segundo vertido hasta el 100%.
- 1:45: revolver suave para bajar residuos de las paredes.
- Caída objetivo: 3:00 a 3:15 para 300 ml. Para 600 ml, 3:45 a 4:00 (tolerancia hasta ~4:15).
